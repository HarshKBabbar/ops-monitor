Database Monitor: next phase

This module will compare, for each SpiceJet airport:

  • AAI eAIP: AD 2.12 runway characteristics, AD 2.13 declared distances, AD 2.10 obstacles (checked every AIRAC)
  • Jeppesen / JetPlan: same fields, once access is set up
  • Our internal Excel database: runway / airport and obstacle data

Every difference will be listed with the same colour system (yellow = to review, green = actioned) and e-mailed to the team.

Needed to start: a sample of the internal Excel sheet and the list of airports.
